# GoLive Classes - Admin Credentials

This file contains the test credentials for the various roles in the GoLive LMS platform.

## Super Admin
Has full access to the HQ Dashboard, user management (block/delete), and course reviews.
- **Email:** `superadmin@golive.com`
- **Password:** `superadmin`
- **Dashboard URL:** `http://localhost:3000/superadmin`

## Teacher / Instructor (Admin)
Can create, edit, and submit courses for review.
- **Email:** `admin@golive.com`
- **Password:** `admin`
- **Dashboard URL:** `http://localhost:3000/admin`

## Student / Learner
Standard user account. Can browse, buy, and consume courses.
*(You can register any new account via the `/register` page to test this role)*
